# Retail Store Database (SQL)

## Objective
Design a retail database and write SQL queries to answer revenue, customer and product questions.

## Database Design
6 tables: Customers, Products, Orders, Order_Items, Payments, Product_Reviews

## Concepts Covered
- Filtering (WHERE, ORDER BY)
- Aggregations (GROUP BY, HAVING)
- Joins (INNER, LEFT, RIGHT)
- Subqueries
- Set operations

## Project Files
- 01_create_database.sql: creates the tables and inserts data
- 02_queries.sql: 40+ queries with solutions
- SQL_Retail_Store_Project.pdf: full project report with query output screenshots
